# Project instructions

## Publishing changes

Whenever pushing this project, push the same intended branches and tags to both
remotes:

- `origin`: GitHub, `https://github.com/brandonhaslegs/dot-diary.git`
- `rad`: Radicle, repository `rad:z3gkDi3uPJkesCqiwqjxbmLWefJep`

This is the user's standing preference. A request to push includes both remotes
unless the user explicitly says otherwise. After pushing to Radicle, synchronize
with the network and verify replication. Report any remote that fails; do not
describe a partial push as fully published. Preserve remote history and do not
force-push to resolve divergence without explicit authorization.
